# player-scouting — web

Frontend en Next.js del proyecto [player-scouting](../README.md). Consume la
API FastAPI del repositorio raíz (`../src/`); no tiene lógica de negocio
propia.

Instrucciones completas de arranque (backend + web) en el
[README principal](../README.md#arrancar-la-web).

```bash
npm install
cp .env.local.example .env.local   # NEXT_PUBLIC_API_URL
npm run dev
```
